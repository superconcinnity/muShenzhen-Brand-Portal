# Repository entry for agents

Read AGENT-GUIDE.md first. For official key visual extensions (square/landscape/portrait, theme posters), read assets/key-visuals/system/README.md and contract.json before designing. The square layout grid applies to both background blocks and decorative symbols; it is distinct from the internal full-logo grid. Use canonical assets, not retyped/generated imitations. Run checks against the actual exported SVG and inspect the rendered image. Named templates have local AGENTS.md and remain governed by their own approved rules.
