# 资产来源

| 文件 | 来源与用途 |
| --- | --- |
| assets/template.svg | 从用户提供的Frame 136 3.svg提取；保留固定文字、Logo、色块和遮罩。Frame 136 2.svg使用相同几何和照片，配色不同 |
| assets/factory-photo.png | 从用户原稿提取的4003 × 2252工厂照片，只存一份 |
| assets/IBMPlexSansSC-Medium.woff2 | [IBM官方仓库](https://github.com/IBM/plex/blob/master/packages/plex-sans-sc/fonts/complete/woff2/hinted/IBMPlexSansSC-Medium.woff2)，用于中文Medium 500 |
| assets/ChakraPetch-SemiBold.ttf | 用户本机已安装的Chakra Petch字体，用于英文SemiBold 600 |
| examples/*.png | 当前模板生成的两种配色示例 |

字体分别遵循包内IBMPlexSansSC-OFL.txt、ChakraPetch-OFL.txt。品牌素材使用条件见仓库[USAGE.md](../../USAGE.md)，照片按自身授权处理。其他品牌的网上测试照片与成品不随包分发。
