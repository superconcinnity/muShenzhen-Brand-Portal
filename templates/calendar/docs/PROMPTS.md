# 可直接发给 agent 的指令

## 初次接手
读取AGENTS.md、README.md与docs/DESIGN.md，安装依赖，生成当前日历并检查PNG。先保持内容和视觉不变，把成图给我。

## 更新活动
读取AGENTS.md。根据我提供的活动表更新content.js，同时在docs/full-schedule.json保留完整信息及来源。每格只留下当日关键活动，保持26px字号，过长时提炼或换行。保留品牌视觉，导出PNG和SVG。

## 读取Notion
读取AGENTS.md。打开这个公开Notion活动链接，切换到完整列表并加载全部条目，核对具体活动日期和取消状态，不能只读Overview。用实际有日期的活动更新海报；未定日期不硬填。按我们的编辑规则提炼标题，生成成图。

## 修改重点日
把12月15日设为Intelligence Week重点日，整格品牌粉色、黑字。其他内容保持原样，生成PNG和SVG。

## 更换图片
用我提供的三张照片替换底部身体练习、户外与街景图，保留位置和比例，检查主体没有被裁掉。更新来源记录，生成PNG和SVG。

## 精简标题
检查所有活动短标题，优先保留当日重点，删除次要并列活动与冗长描述。全部日历标题保持26px，底部标题保持32px，不可单独缩小。修改后检查溢出并出图。
