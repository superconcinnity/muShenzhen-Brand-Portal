# City Maker 模板：Agent 执行规则

适用于本目录。目标是复用确认后的版式换人出图，不重新设计。先阅读 README.md、content.json、template-rules.json；仓库根目录品牌规则同时适用。本模板用户已确认的字号、强调色、页脚大小写为本模板的具体约定。

## 默认操作

1. 收集五项内容：图片、公司／项目英文名、角色英文名、姓名（中文／英文／双语）、中文一句话描述。缺失事实不能猜测；已有信息足够时直接执行。
2. 照片放在 assets/，使用相对路径。不引用制作者电脑路径、临时目录或远程热链。
3. 优先只修改人物配置，保留主标题、logo、网址、年份、页脚、字体、颜色与布局。
4. 用 npm ci 安装锁定依赖；首次 npm run setup 安装浏览器。npm run check 检查默认配置，npm run render 导出并完整校验。多人使用独立 JSON 和输出目录，见 README。
5. 检查预览中的人脸裁切、标签遮挡和文字可读性。不能仅因脚本退出码为0就跳过视觉检查。
6. 交付 PNG、SVG、HTML 与预览，说明有无文案精简、来源和真实限制。随发布说明注明“视觉素材来源：mushenzhen”。

## 不得破坏的规则

- 公司／项目与姓名同为64；角色与中文介绍同为40。字号不得因文字长度改变，不能压缩字宽、截断姓名或靠省略号掩盖关键内容。
- 绿色标签 Hug Contents：实际文字宽高 + 四边18内边距，右上两标签右对齐、零间距。
- 角色在上，公司／项目在下。角色必须单行，背景向左延长；不得为了固定448宽度强行折行。角色最大宽度是整个安全区1236。
- 姓名在中文介绍上方；两个标签左侧错位，零间距，整体底部贴齐照片底部。
- 除角色外最多两行，英文在单词之间换行。遵循 template-rules.json 中字符数、宽度和安全区约束。
- 所有内容包括标签都不得越过安全区。报错时精简真实文案，或在用户明确要求调整规则时修改参数；不得放宽检查只为通过。
- 保留品牌原矢量路径与比例，不重打、生成或拉伸 logo。保留其与英文标题大写字母的上下对齐关系。
- 图片保持比例填充。建议使用干净、足够清晰的原图；不使用旧成品截图裁出带标签的照片。
- 对长姓名保留真实拼写；中文名可直接使用，不强制转换成英文，不擅自加入未经提供或核验的译名。
- 网址和页脚 Regular 400，不加粗。

## 文案与来源

- 公司／项目：2–18字符；角色：2–24；姓名：2–24；中文一句话描述：8–24。字母、内部空格、标点、汉字均计数。
- 描述先提炼最核心且真实的项目贡献；事实不够时询问，不补造头衔、排名或嘉宾身份。
- 若用户要求用网上人物测试，核对来源并在测试配置中设置 testOnly: true；测试不等于活动邀请或背书。
- 不默认将网上人物照片推入公有仓库或用于正式宣传。

## 文件位置

content.json：默认人物；template-rules.json：字号和限制；render.cjs：排版与导出；validate.cjs：字段校验；assets/：字体、许可、logo和照片；examples/：已确认预览。

渲染失败时不能交付旧输出。不要自动提交或推送同事的人物资料；只在该次任务明确要求上传时执行。
