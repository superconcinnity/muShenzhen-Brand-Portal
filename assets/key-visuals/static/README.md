## 编辑与字体（前四张 SVG）

SVG 画幅为 595 × 842。信息文字保留 SVG text；Logo 和符号为矢量路径；三张主题海报各有一张内嵌图片，不依赖外部图片链接。

需要字体：Chakra Petch（Medium 500、SemiBold 600、Bold 700）、IBM Plex Sans SC（SemiBold 600）、BL Melody Mono（Regular 400）。每张具体依赖见 assets.json。字体文件没有收入本包。

先安装匹配字体，再在 Illustrator 中以“打开”方式载入 SVG。不同软件可能重新计算字距，编辑后应对照 PNG。未进行 Illustrator 实机验证。浏览器预览不一定自动加载本机字体；需要一致外观时使用 PNG。

## 发布前需注意

- 发布版 SVG 和 PNG 不显示辅助网格。此前预览中的细线是矩形拼接的抗锯齿接缝，并非独立网格图层，发布版已修正。辅助网格只用于编辑，不收入发布成品。
- 日期与活动信息保留各海报原稿内容。Human Flourishing 明确标注 2026；其余海报未注明年份，不应自动视为当前活动公告。
- 海报中的 Logo 保留该版本，不自动替换为后续确认的品牌方格 Logo。
- 品牌视觉元素使用必须提到 mushenzhen；内嵌照片的公开分发范围需要单独确认，不自动适用元素与模板的商用政策。

本目录收录已确认的静态主视觉；SVG 也是静态版本，格式可编辑不代表动态素材。文件与校验值见 [assets.json](assets.json)。
