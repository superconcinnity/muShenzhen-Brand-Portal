# 主视觉 / Key visuals

按表现形式归档，同一主题可延展不同尺寸与版本。

| 分类 | 状态 | 入口 |
|---|---|---|
| 静态主视觉 | 已收录 7 张海报，含 PNG、JPG 与部分 SVG | [预览与下载](static/README.md) |
| 动态主视觉 | 后续扩展，当前未收录 | 未来使用 `motion/` |

静态 SVG 是可编辑的静态画面，不归为动态资产。动态 Logo 属于 Logo 类别，未来放在 `assets/logos/motion/`，不与动态主视觉混放。现有完整版、简化版 Logo 路径保持不变。

动态资产到位后，再记录对应主题、格式、时长、循环方式、尺寸和预览；没有文件的分类不提供下载入口。
